\textbf{a)} The affine coordinate ring is defined by the formula $A(Y)=k[x,y]/I(Y)$. In this instance, $I(Y)=(y-x^2)$ as $(y-x^2)$ is a radical ideal. Let $\varphi:k[x,y]\to k[x]$ be the morphism defined by $x\mapsto x$ and $y\mapsto x^2$. This is surjective and $\ker(\varphi)=(y-x^2)$, so that $A(Y)\cong k[x]$.\\\\

\textbf{b)} We have $A(Z)=k[x,y]/(1-xy)$. This is in fact isomorphic to $k[x]_x$. To see this, define a morphism $\varphi:k[x,y]\to k[x]_x$ by $x\mapsto x$ and $y\mapsto x^{-1}$. Then $\varphi$ is a surjection and its kernel is exactly $(1-xy)$.\\\\
%
\textbf{c)} First note that if $p(x,y)$ is a homogeneous polynomial of degree $n$ in $k[x,y]$, where $k$ is an algebraically closed field, then $p$ splits into a product of linear factors. To see this write $p=y^ng(\frac{x}{y})$. Then $g(\frac{x}{y})$ will split so we can write $p=y^n(\frac{x}{y}-a_1)...(\frac{x}{y}-a_n)=(x-a_1y)...(x-a_ny)$.\\
        
        Now, suppose that $f(x,y)$ is an irreducible quadratic over an algebraically closed field $k$. Let $p(x,y)$ be the degree 2 homogeneous part of $f$. By the above we can write $p=(ax-by)(cx-dy)$. Potentially swapping variables we can assume without loss of generality that $a\neq 0$. If these factors are linearly dependent, we can do a change of variables to replace $x$ with $ax-by$ (note that replacing $x$ with a linear polynomial in $x$ and $y$ induces an automorphism of $k[x,y]$). Then $f(x,y)=x^2+ax+by+c$. We can then do a change of variables and replace $ax+by+c$ with $-y$, giving $f(x,y)=x^2-y$. Solving $f=0$ then gives $y=x^2$.\\
        
        If both factors are linearly independent, we can assume that $a,d\neq 0$. Thus by a change of variables (replacing $ax-by$ with $x$ and $cx-dy$ with $y$, which induces an automorphism of $k[x,y]$ as these factors are linearly independent) we can write $f(x,y)=xy+ax+by+c$. We then have $f(x,y)=(x+b)(y+a)+c-ab$. Another change of variables then allows us to write $f(x,y)=xy-1$. Solving for $f=0$ then gives $xy=1$.\\\\

\textbf{2.6}:\\
We will use the following lemma:
\begin{lemma}
\label{lem:indet_map}
If a ring map $f: A \lto B$ is injective and extends to a map $F: A[\lbrace x_i\rbrace_{i \in I}] \lto B$ such that the ideal generated by $\lbrace x_i\rbrace_{i \in I}$ has empty intersection with $\ker{F}$, then $F$ is injective.
\end{lemma}
\begin{proof}
Clearly a non-zero element of $A[\lbrace x_i\rbrace_{i \in I}]$ maps to a non-zero element of $B$.
\end{proof}
There is a map
\begin{align*}
    S &\lto S_{(x_i)}\\
    f &\mapsto f(x_0/x_i,...,x_n/x_i)
\end{align*}
and thus a composite
\[
\psi_i: A \stackrel{\beta_i}{\lto}S\lto S_{(x_i)}
\]
given by $f \mapsto x_i^{\operatorname{deg}f}f(x_0/x_i,...,x_n/x_i) \mapsto f(x_0/x_i,...,x_n/x_i)$ (with $x_i/x_i$ omitted). This map is clearly an isomorphism as it is just a relabelling of indeterminants. In fact, we have:
\begin{lemma}
Let $Y \subseteq \bb{P}^n$ be a projective variety, $f \in I(Y_i)$, and $P \in Y \cap U_i$. Then
\[f(\varphi_i(P)) = 0 \Longleftrightarrow (\beta_i f)(P) = 0\]
Moreover, if $P \not\in U_i$ then $P_i = 0$ and so $(\beta_i f)(P) = 0$. Thus $f \in I(Y_i) \Rightarrow \beta_i(f) \in I(Y)$.
\end{lemma}
Thus $\psi_i(I(Y_i)) = I(Y)S_{(x_i)}$, and so \[\varphi_i^\ast: A(Y_i) \lto S_{(x_i)}/(I(Y)S_{(x_i)}) \cong S(Y)_{(x_i)}\]
    is an isomorphism.

This extends naturally to a surjective map $A(Y_i)[x_i] \lto S(Y)_{x_i}$, the image of $x_i$ under which is a unit, we thus have a map 
\[
    \delta_i: \big(A(Y_i)[x_i]\big)_{x_i} \lto S(Y)_{x_i}
\]
our next claim is that this is an isomorphism. This maps onto a set of generators and is thus surjective. For injectivity, as $A(Y_i)[x_i]$ is an integral domain, it suffices to show $A(Y_i)[x_i] \lto S(Y)_{x_i}$ is injective, which follows from Lemma \ref{lem:indet_map}.

We now show $\operatorname{dim}S(Y)_{x_i} = \operatorname{dim}S(Y) - 1$. By $(1.8A)$ this equality is equivalent to $\operatorname{tr.deg}_kS(Y)_{x_i} = \operatorname{tr.deg}_kS(Y) - 1$. We have
\begin{align*}
\operatorname{Frac}S(Y) &\cong \operatorname{Frac}S(Y)_{x_i}\\
&\cong\operatorname{Frac}\big(A(Y_i)[x_i]\big)_{x_i}\\
&\cong \operatorname{Frac}\big(A(Y_i)[x_i]\big)\\
&= \big(A(Y_i)\big)(x_i)\\
&\cong \big(S(Y)_{x_i}\big)_0(x_i)
\end{align*}
thus
\[\operatorname{tr.deg}_kS(Y) = \operatorname{tr.deg}_k\big(S(Y)_{x_i}\big)_0(x_i) = \operatorname{tr.deg}\big(S(Y)_{x_i}\big)_0 + 1\]

We also have that
\[\operatorname{dim}\big(S(Y)_{x_i}\big)_0 = \operatorname{dim}A(Y_i) = \operatorname{dim}(Y \cap U_i)\]

Thus $\operatorname{dim}S(Y) = \operatorname{dim}(Y\cap U_i) + 1$ for all $i$, notice this value is independent of $i$ and so by exercise $1.10b)$ we have $\operatorname{dim}S(Y) = \operatorname{dim}Y + 1$.\\\\

\begin{remark}[Generators for the twisted cubic ideal]
\label{rem:twisted_cubic_generators}
Let $\overline{Y}\subset \bb{P}^3$ be the projective closure of the affine curve
$t\mapsto (t,t^2,t^3)$, so that in homogeneous coordinates $[w:x:y:z]$ we have the parametrisation
\[
t\longmapsto [1:t:t^2:t^3].
\]
Equivalently, $\overline{Y}$ is the image of the $3$-uple embedding $\rho_3:\bb{P}^1\to \bb{P}^3$,
\[
[s:t]\longmapsto [t^3:st^2:s^2t:s^3].
\]
Let $S=k[w,x,y,z]$ and define the graded map
\[
\psi:S\to k[s,t],\qquad w\mapsto t^3,\ x\mapsto st^2,\ y\mapsto s^2t,\ z\mapsto s^3.
\]
Then $I(\overline{Y})=\ker\psi$.

The three quadrics
\[
f_1=wy-x^2,\qquad f_2=wz-xy,\qquad f_3=xz-y^2
\]
all vanish under $\psi$, hence $(f_1,f_2,f_3)\subseteq \ker\psi$.

To see equality, note that $(f_1,f_2,f_3)$ has the two linear syzygies
\[
(-y)f_1 + x f_2 + (-w)f_3 = 0,\qquad
z f_1 + (-y)f_2 + x f_3 = 0,
\]
so there is a graded free resolution
\[
0\to S(-3)^2 \to S(-2)^3 \to S \to S/(f_1,f_2,f_3)\to 0.
\]
Hence the Hilbert series of $S/(f_1,f_2,f_3)$ is
\[
H_{S/(f_1,f_2,f_3)}(t)=\frac{1-3t^2+2t^3}{(1-t)^4}=\frac{1+2t}{(1-t)^2},
\]
so $\dim_k(S/(f_1,f_2,f_3))_m = 3m+1$ for all $m\ge 0$.

On the other hand, $\im\psi$ is the $3$rd Veronese subring
$\bigoplus_{m\ge 0}k[s,t]_{3m}$, whose degree-$m$ piece has dimension $3m+1$.
Thus $S/(f_1,f_2,f_3)\twoheadrightarrow \im\psi$ is a graded surjection with the same Hilbert function,
hence an isomorphism. Therefore $\ker\psi=(f_1,f_2,f_3)$ as claimed.
\end{remark}}\\\\

\textbf{b)} We begin by establishing the following lemma:
\begin{lemma}
\label{lem:lin_codimension}
Let $f_1,...,f_m$ be a set of linear polynomials in $S$. Then $\operatorname{dim}S/(f_1,...,f_m) = n + 1 - m$.
\end{lemma}
\begin{proof}
Since $S/(f_1,...,f_m) \cong \big(S/(f_1,...,f_{m-1})\big)/\overline{(f_m)}$ it suffices to prove the case when there is a single $f_i$, say $f$. Write $f = \alpha_0 x_0 + \hdots + \alpha_n x_n$ and by reordering the variables if necessary assume $\alpha_0 \neq 0$. Consider the map $k[x_0,...,x_n] \to k[x_1,...,x_n]$ which maps $x_i \mapsto x_i$ for $i \geq 1$ and $x_0 \mapsto \alpha_0^{-1}(-\alpha_1x_2 - ... - \alpha_nx_n)$. This induces an isomorphism $k[x_0,...,x_n]/(f) \cong k[x_1,...,x_n]$ and the result follows.
\end{proof}
Now proceeding with the question at hand. Let $Y$ have dimension $r$ and write $Y = Z(f_1) \cap ... \cap Z(f_m) = Z(f_1,...,f_m)$ where each $Z(f_i)$ is a hyperplane, and moreover assume $m$ is minimal amongst such decompositions. We have:
\[r + 1 = \operatorname{dim}Y + 1 = \operatorname{dim}S(Y) = n + 1 - m\]
and thus $m = n - r$.\\
\textbf{c)}: The solution to this question essentially comes down to the following observation:
\begin{lemma}
\label{lem:vectorised_variety}
A linear variety $Y$ in $\bb{P}^n$ is a $k$-vector subspace of $\bb{A}^{n+1}$ and the dimension of $Y$ as a variety is one less than its dimension as a vector space.
\end{lemma}
\begin{proof}
That $Y$ is a $k$-vector subspace is obvious, we prove the second claim by induction on $n - \operatorname{dim}Y$. If $\operatorname{dim}Y = n$ then $Y$ is the whole space and so as a subspace of $\bb{A}^{n+1}$ has dimesion $n+1$. For the inductive step, assume $\operatorname{dim}Y = k$ and that $\lbrace y_1,...,y_{k+1}\rbrace$ is a basis for $Y$ as a subspace of $\bb{A}^{n+1}$. For a linear polynomial $f$ such that $Z(f) \cap Y \neq Z(f)$ we have $Y \cap Z(f) = \operatorname{Span}\lbrace y_1,...,y_{k+1}\rbrace \cap Z(f)$. Write $f = \alpha_0 x_0 + ... + \alpha_n x_n$, then $Y \cap Z(f)$ is the span of the vectors $y_1,...,y_{k+1}$ subject to the condition $y_i^0 = \alpha_0^{-1}(-\alpha_1 y_i^1 - ... - \alpha_n y_i^n)$, and so has dimension 1 less than that of $Y$. What we have shown is that as $Y$ decreases by 1 in dimension as a variety, so to does it decrease by 1 in dimension as a subspace.
\end{proof}
The question at hand is now reduced to elementary linear algebra.\\\\

We use the following Lemma:
\begin{lemma}
\label{lem:torture}
Let $X$ be an affine variety and $U \subseteq X$ a quasi-affine variety. Write $U = Z(\frak{a})^c$ There is a bijection:
\begin{align*}
    \psi: \lbrace \text{Irreducible, closed subsets }V \subseteq U\rbrace &\lto \lbrace \text{Irreducible closed subsets }V \subseteq X\text{ such that }V \not\subseteq Z(\frak{a})\rbrace\\
    V &\mapsto \operatorname{Cl}_X(V)
\end{align*}
\end{lemma}
\begin{proof}
First we show this map is well defined. Irreducibility is transitive (Lemma \cite[\S Irreducible sets]{alggeonotes}) so since $V$ is an irreducible subset of $U$ it is also of $X$, moreover the closure of an irreducible space is irreducible, thus $\bar{V}$ is irreducible. It is clearly also closed and not contained in $Z(\frak{a})$ otherwise it must have been the empty set which is not irreducible.

There is an inverse $\varphi$ to this function which maps $V$ to $V \cap U$. This is also clearly well defined, where we note that $V \cap U \neq \varnothing$ as $V \not\subseteq Z(\frak{a})$.

Now we show this is in fact a bijection. $\varphi \psi (V) = \operatorname{Cl}_X(V) \cap U$. Since $V \subseteq U$ is closed, write $V = V' \cap U$ where $V' \subseteq X$ is closed. We claim $\operatorname{Cl}_X(V' \cap U) \cap U = V$. We have $V \subseteq U$ and $V = V' \cap U$ so $V \subseteq \operatorname{Cl}_X(V' \cap U) \cap U$. We show the reverse inclusion. $V'$ is a closed set containing $V' \cap U$ and so $\operatorname{Cl}_X(V' \cap U) \subseteq V'$, thus $\operatorname{Cl}_X(V' \cap U) \cap U \subseteq V' \cap U = V$. Thus $\varphi\psi(V) = V$.

Conversely, we need to show $\operatorname{Cl}_X(W \cap U) = W$, but this is true as $U$ is open and thus dense.
\end{proof}
In particular, Lemma \ref{lem:torture} implies that fpr any $P \in U$, there is a bijection between the irreducible, closed neighbourhoods of $P \in U$ and the irreducible, closed neighbourhoods of $P \in X$.\\\\

which is injective and identifies $U_i$ homeomorphically with a closed subset of the corresponding affine chart of $\mathbb P^N$.
Since the $U_i$ cover $\mathbb P^n$, it follows that $\rho_d$ is a homeomorphism onto the closed subset $Z(\mathfrak a)$.

\medskip
\textbf{(d)} For $(n,d)=(1,3)$ one has

\rho_3([s:t])=[s^3:s^2t:st^2:t^3]\subset \mathbb P^3,
\]
and the kernel ideal is the twisted cubic ideal
\[
\ker\theta=(wy-x^2,\; wz-xy,\; xz-y^2).
\]

\textbf{2.15(a)} (Segre $\mathbb P^1\times\mathbb P^1\to\mathbb P^3$ kernel):
Let $S=k[z_{00},z_{01},z_{10},z_{11}]$ and $T=k[x_0,x_1,y_0,y_1]$.
Define
\[
\theta:S\to T,\qquad z_{ij}\mapsto x_i y_j,
\]
and let $\Delta=z_{00}z_{11}-z_{01}z_{10}$.

\medskip
\textbf{Claim.} $\ker\theta=(\Delta)$.

\begin{proof}
We have $\Delta\in\ker\theta$ since
\[
\theta(\Delta)=(x_0y_0)(x_1y_1)-(x_0y_1)(x_1y_0)=0,
\]
so $(\Delta)\subseteq\ker\theta$.

The image of $\theta$ is the diagonal bihomogeneous subring
\[
R:=\bigoplus_{d\ge 0} T_{(d,d)},
\]
so $\theta$ induces a graded surjection $S/(\Delta)\twoheadrightarrow R$.

Compute Hilbert functions. For $d\ge 0$,
\[
\dim_k R_d=\dim_k T_{(d,d)}=(d+1)(d+1)=(d+1)^2.
\]
Also
\[
\dim_k(S/(\Delta))_d=\dim_k S_d-\dim_k S_{d-2}=\binom{d+3}{3}-\binom{d+1}{3}=(d+1)^2.
\]
Thus the induced graded surjection is an isomorphism in every degree, hence $\ker\theta=(\Delta)$.
\end{proof}

\textbf{3.6}:
Let $X=\mathbb A^2\setminus\{(0,0)\}$ over an algebraically closed field $k$.

\medskip
\textbf{Claim 1.} $\Gamma(X,\mathcal O_X)=k[x,y]$.

\begin{proof}
Cover $X$ by $D(x)$ and $D(y)$. Then
\[
\Gamma(D(x),\mathcal O)=k[x,y]_x,\qquad \Gamma(D(y),\mathcal O)=k[x,y]_y,
\]
and on the overlap $D(xy)$,
\[
\Gamma(D(xy),\mathcal O)=k[x,y]_{xy}.
\]
By the sheaf condition,
\[
\Gamma(X,\mathcal O)=k[x,y]_x\cap k[x,y]_y \subset k(x,y).
\]
Take $f\in k[x,y]_x\cap k[x,y]_y$. Write $f=a/x^m=b/y^n$ with $a,b\in k[x,y]$.
Then $y^n a=x^m b$. Since $k[x,y]$ is a UFD and $(x,y)=1$, we have $x^m\mid a$.
Write $a=x^m c$, so $f=c\in k[x,y]$. Hence the intersection equals $k[x,y]$.
\end{proof}

\medskip
\textbf{Claim 2.} $X$ is not affine.

\begin{proof}
If $X$ were affine, then $X\cong \operatorname{Spec}\Gamma(X,\mathcal O_X)\cong \operatorname{Spec}k[x,y]=\mathbb A^2$,
contradiction since $X\neq \mathbb A^2$ (it is missing a closed point).
\end{proof}

\textbf{3.8} (correct statement):
\[
\Gamma(\mathbb P^n,\mathcal O_{\mathbb P^n})=k.
\]

\begin{proof}
Let $f\in \Gamma(\mathbb P^n,\mathcal O)$.
In the function field $K(\mathbb P^n)$ we can write $f=F/G$ with $F,G\in k[x_0,\dots,x_n]$ homogeneous of equal degree and
$\gcd(F,G)=1$.
Since $f$ is regular everywhere, $G$ is nowhere zero on $\mathbb P^n$.
If $\deg G>0$, then $Z(G)\subset \mathbb P^n$ is a nonempty hypersurface (over an algebraically closed field), contradiction.
Hence $\deg G=0$, so $G\in k^\times$, and then $\deg F=0$ as well, so $F\in k$.
Thus $f\in k$.
\end{proof}

\bigskip

\textbf{3.15(d)} (dimension of product):
Let $X,Y$ be irreducible affine varieties over $k$ with coordinate rings $A=A(X)$ and $B=A(Y)$.
Then $A,B$ are finitely generated $k$-domains and
\[
A(X\times Y)\cong A\otimes_k B.
\]
We show $\dim(A\otimes_k B)=\dim A+\dim B$.

\begin{proof}
Let $r=\dim A$ and $s=\dim B$.
By Noether normalization, there exist algebraically independent elements $u_1,\dots,u_r\in A$ such that
$A$ is integral over $k[u_1,\dots,u_r]$, and similarly $v_1,\dots,v_s\in B$ such that
$B$ is integral over $k[v_1,\dots,v_s]$.

Set $R:=k[u_1,\dots,u_r,v_1,\dots,v_s]\cong k[u_1,\dots,u_r]\otimes_k k[v_1,\dots,v_s]$.
The natural map $R\to A\otimes_k B$ (sending $u_i\mapsto u_i\otimes 1$, $v_j\mapsto 1\otimes v_j$) is injective.

Since $A$ is integral over $k[u]$, each $a\otimes 1\in A\otimes B$ is integral over $R$.
Similarly, each $1\otimes b$ is integral over $R$.
Because $A\otimes_k B$ is generated over $R$ by $A\otimes 1$ and $1\otimes B$, it follows that $A\otimes_k B$ is integral over $R$.

Integral extensions preserve Krull dimension, hence
\[
\dim(A\otimes_k B)=\dim R=r+s=\dim A+\dim B.
\]
Therefore $\dim(X\times Y)=\dim X+\dim Y$.
\end{proof}

\bigskip

\textbf{3.17(b)} (quadric surface is normal):
Let $Q\subset \mathbb P^3$ be $Q=Z(x_0x_1-x_2x_3)$.

\begin{proof}
Let $F=x_0x_1-x_2x_3$. Then
\[
\partial_{x_0}F=x_1,\quad \partial_{x_1}F=x_0,\quad \partial_{x_2}F=-x_3,\quad \partial_{x_3}F=-x_2.
\]
These vanish simultaneously only at $(0,0,0,0)$, which is not a point of $\mathbb P^3$.
Hence $Q$ is nonsingular.

All local rings of a nonsingular variety are regular local domains, hence integrally closed.
Therefore $Q$ is normal.
\end{proof}

\bigskip

\textbf{3.17(c)} (cusp is not normal):
Let $C=Z(y^2-x^3)\subset \mathbb A^2$ and $P=(0,0)$.
Set $A=k[x,y]/(y^2-x^3)$ and localize at $\mathfrak m=(x,y)$.

\begin{proof}
Embed $A$ into $k[t]$ via $x\mapsto t^2$, $y\mapsto t^3$, identifying $A\cong k[t^2,t^3]$.
Under this embedding, $A_{\mathfrak m}$ maps into $k[t]_{(t)}$ and consists of fractions
\[
\frac{f(t^2,t^3)}{g(t^2,t^3)}\quad\text{with }g(0)\neq 0.
\]
Let $u:=y/x\in \operatorname{Frac}(A)$. In $k(t)$ this is $u=t^3/t^2=t$.
Moreover $u$ is integral over $A_{\mathfrak m}$ since
\[
u^2 = \frac{y^2}{x^2}=\frac{x^3}{x^2}=x,
\]
so $u$ satisfies the monic polynomial $T^2-x\in A_{\mathfrak m}[T]$.

We claim $u\notin A_{\mathfrak m}$. Indeed, any element of $A_{\mathfrak m}$ has the form
$f(t^2,t^3)/g(t^2,t^3)$ with $g(0)\neq 0$.
Expanding in $k[[t]]$, both $f(t^2,t^3)$ and $g(t^2,t^3)$ involve only exponents in the semigroup
$\langle 2,3\rangle=\{0,2,3,4,5,\dots\}$, hence have no $t^1$ term.
Since $g(0)\neq 0$, $1/g(t^2,t^3)$ is a power series also with no $t^1$ term.
Therefore the product $f/g$ has no $t^1$ term.
But $u=t$ \emph{does} have a $t^1$ term, contradiction.
Thus $u\notin A_{\mathfrak m}$.

Hence $A_{\mathfrak m}$ is not integrally closed, so $C$ is not normal at $P$.
\end{proof}

\subsection{Chapter II, \S 1}

\textbf{1.1} (constant sheaf):
Let $A$ be an abelian group. Let $C_A$ denote the constant presheaf:
$C_A(\varnothing)=0$ and $C_A(U)=A$ for $U\neq\varnothing$, with restriction maps the identity.
Let $\mathscr A$ denote the constant sheaf associated to $A$.

\medskip
\textbf{Claim.} If $U=\bigsqcup_{i\in I}U_i$ is the decomposition of $U$ into connected components, then
\[
\mathscr A(U)\cong \prod_{i\in I} A.
\]

\begin{proof}
A section of $\mathscr A$ over $U$ is a locally constant map $s:U\to A$.
Any locally constant map is constant on each connected component $U_i$, hence determines an element $a_i\in A$ for each $i$.
Conversely, given $(a_i)_{i\in I}\in \prod_{i\in I}A$, define $s$ by $s|_{U_i}\equiv a_i$; this is locally constant.
These constructions are inverse and are compatible with restriction maps, giving the desired identification.

In particular, if $U$ is connected then $\mathscr A(U)\cong A$.
Moreover, one checks directly from the sheafification universal property that $C_A^+$ is precisely this sheaf of locally constant
$A$-valued functions, so $C_A^+\cong \mathscr A$.
\end{proof}

\textbf{2.11}:

\medskip
\textbf{Prime ideals.}
Since $k[x]$ is a PID, every nonzero prime ideal is generated by an irreducible polynomial.
Thus
\[
\operatorname{Spec}(k[x])=\{(0)\}\ \cup\ \{(f)\mid f\in k[x]\ \text{irreducible}\}.

The generic point is $(0)$, and the closed points are exactly the maximal ideals $(f)$ with $f$ irreducible.

\[
k(\mathfrak p)\cong k[x]/(f)\cong \mathbb F_{p^{d}}.
\]
If $\mathfrak p=(0)$, then
\[
k(\mathfrak p)=\operatorname{Frac}(k[x])=k(x).
\]

\section{B\'ezout's Theorem (plane curves)}
\label{sec:bezout}

\begin{thm}
Let $k$ be algebraically closed and let $F,G\in k[x,y,z]$ be homogeneous polynomials of degrees
$m=\deg F$ and $n=\deg G$. Assume $F$ and $G$ have no common component (equivalently, $\gcd(F,G)=1$ in $k[x,y,z]$).
Let
\[
Z = Z_{\bb{P}^2}(F)\cap Z_{\bb{P}^2}(G)=\operatorname{Proj}\big(k[x,y,z]/(F,G)\big).
\]
Then $Z$ is $0$-dimensional and
\[
\sum_{P\in |Z|}\operatorname{length}_{\mathcal{O}_{\bb{P}^2,P}}\big(\mathcal{O}_{\bb{P}^2,P}/(F,G)\big)=mn.
\]
In particular, the set-theoretic intersection is finite.
\end{thm}

\begin{proof}
Let $S=k[x,y,z]$.
Since $F\neq 0$ and $S$ is a domain, multiplication by $F$ is injective, giving the graded exact sequence
\[
0\to S(-m)\xrightarrow{\cdot F} S \to S/(F)\to 0.
\]
Hence
\[
H_{S/(F)}(t)=(1-t^m)H_S(t).
\]

We claim that $G$ is not a zero-divisor in $S/(F)$.
Indeed, if $HG\in (F)$ in $S$ with $H\notin (F)$, then $F\mid HG$.
Since $\gcd(F,G)=1$ in the UFD $S$, it follows that $F\mid H$, contradiction. Thus multiplication by $G$ on $S/(F)$ is injective.

Therefore we have another graded exact sequence
\[
0\to (S/(F))(-n)\xrightarrow{\cdot G} S/(F) \to S/(F,G)\to 0,
\]
so
\[
H_{S/(F,G)}(t)=(1-t^n)H_{S/(F)}(t)=(1-t^m)(1-t^n)H_S(t).
\]
Since $H_S(t)=\frac{1}{(1-t)^3}$, we get
\[
H_{S/(F,G)}(t)=\frac{(1-t^m)(1-t^n)}{(1-t)^3}.
\]

Let $h(d)=\dim_k (S/(F,G))_d$ be the Hilbert function.
For $d\gg 0$, $h(d)$ equals the Hilbert polynomial, and because $Z$ is $0$-dimensional this polynomial is constant
and equals $\deg(Z)$ (the degree/length of the $0$-dimensional projective scheme).

Using $\dim_k S_d=\binom{d+2}{2}$ and the above Hilbert series identity, for all $d\gg 0$ one has
\[
h(d)=\binom{d+2}{2}-\binom{d-m+2}{2}-\binom{d-n+2}{2}+\binom{d-m-n+2}{2}=mn.
\]
Hence $\deg(Z)=mn$.

Finally, for a $0$-dimensional projective scheme, the degree equals the sum of the lengths of the local rings at its points:
\[
\deg(Z)=\sum_{P\in |Z|}\operatorname{length}_{\mathcal{O}_{\bb{P}^2,P}}\big(\mathcal{O}_{Z,P}\big)
=\sum_{P\in |Z|}\operatorname{length}_{\mathcal{O}_{\bb{P}^2,P}}\big(\mathcal{O}_{\bb{P}^2,P}/(F,G)\big).
\]
Thus the sum of intersection multiplicities is $mn$.
\end{proof}

\begin{remark}
This is the scheme-theoretic version of B\'ezout for plane curves:
it counts intersection points with multiplicity. The finiteness of $Z(F)\cap Z(G)$ follows immediately.
\end{remark}
